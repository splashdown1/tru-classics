# TRU Classics Offline Packs

## Ready packs (full text)

The complete single-file offline readers are available in the local workspace and as a zip:

- `meditations.html` — full Project Gutenberg #2680 text, TRU-styled reader
- `republic.html` — full Project Gutenberg #1497 (Jowett) text, TRU-styled reader

**Zip of both packs:** `tru-classics-packs.zip` (in the parent directory of this repo on the build machine)

Because of size limits in the automated push path, the full HTML files are not committed here yet.  
To add them:

1. Download the two `.html` files (or the zip)
2. Place them in this `packs/` folder
3. Commit and push

Once added, the shelf at `index.html` already links to:
- `packs/meditations.html`
- `packs/republic.html`

Both packs include:
- Full public-domain text
- Sticky header
- Provenance card
- Clean TRU typography
- Fully offline operation

A gap stays a gap.
