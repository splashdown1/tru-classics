## What this is

A curated, source-bound starting shelf of classical works that fit TRU’s philosophy:

- Public domain only
- Prefer the cleanest available English editions
- No summaries, no modern rewrites that change meaning
- Packaged for true offline use

## Sections

1. **Philosophy & Wisdom** — Meditations, Republic, Nicomachean Ethics, Socratic dialogues, Epictetus
2. **Epic & Foundational Literature** — Odyssey, Iliad, Aeneid
3. **Later Classics** — Confessions, Paradise Lost, Pride and Prejudice, Inferno

## How to grow it the TRU way

1. Prefer **Standard Ebooks** when a high-quality public-domain edition exists.
2. Fall back to **Project Gutenberg** HTML / plain text.
3. Record provenance (title, author, translator, exact source, date).
4. Pack into single-file readers (see `packs/`).
5. A gap stays a gap — do not invent or modernize the text.

Built for offline sovereignty.
